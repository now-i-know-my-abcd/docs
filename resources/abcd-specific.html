ABCD tools & resources#

Last reviewed: October 2026. Know of something we’re missing? Open an issue or use our submission form.

ABCD’s data structure changed completely with Release 6.0 (new BIDS-style IDs, session names, and variable names; distribution moved from NDA to NBDC). Code and tutorials written for earlier releases often won’t run as-is on current data. This page collects official and community resources and sorts them by which release they work with, so you can tell at a glance what’s ready to use. For step-by-step guides (access, downloads, analysis, publishing), see Working with ABCD data.

How releases are tagged#

Badge

Meaning

7.0

Built or updated for the current release (7.0)

any release

Methods, concepts, or tools that don’t depend on ABCD’s data structure

6.x

Built for the NBDC era (6.0/6.1). Usually works on 7.0, but check variable names

≤ 5.1

NDA era. Access steps and variable names are outdated, but the ideas may still help

Tip

Porting old code? NBDCtools::convert_names_data() and convert_names_file() translate pre-6.0 variable names to the new scheme, and the data dictionary lists each variable’s old name. See Accessing the data for the new ID and session conventions.

The official packages are all maintained for 7.0, and ABCDscores’ version number matches the data release (7.x ↔ release 7).

7.0 known issues worth knowing about#

Summarized from the 7.0 release notes and the docs changelog (through docs 7.0.4, October 2026). Always check the official pages for updates.

  • Coverage: 11,860 participants across 16 events. Data are complete through the 5-year follow-up and nearly complete for year 6. The 7-year and 7.5-year (ses-07M) data are partial.

  • Siemens XA30 sessions (889): T1w, T2w, and fieldmaps are missing from BIDS sourcedata/rawdata. Derivatives and tabulated imaging data are not affected.

  • Concatenated voxelwise imaging: an outdated registration target for atlas channel 11 left out cerebellar grey matter.

  • RECOVER COVID-symptom tables (recover_p_ps, recover_p_pscg): 346 variables are misnamed. The release notes give a rename mapping, and a fix is planned for 7.1.

  • fc_y_ev__edu_002__v01 has a mislabeled response level (school type).

  • Documentation-only notes added in 7.0.3–7.0.4: hair-style bias in hair toxicology, a Pubertal Development Scale scoring correction, a body-size caveat for dMRI, mh_y_resil and Emotional Stroop randomization issues.

Warning

Still on 6.0/6.1? These were fixed in 7.0: hair toxicology was coded 1/2 instead of 0/1, the Fitbit qc_300min sleep flag used > 299 instead of ≥ 300, and three ozone variables in le_l_lo3 were mis-mapped. Re-check any results that use these variables.

Found a data problem? Report it through the ABCD issue-reporting page (NBDC Help Center ticket). There’s no public known-issues tracker.

Note

As of October 2026 we couldn’t find any 7.0-specific training (webinar, walkthrough, or office hours). The NBDC 7.0 pages point to the written docs, and the platform and DEAP are unchanged from 6.x, so the 6.x tutorials below still apply. Questions go to nbdc@mail.nih.gov or our Discussion Board.
